# 💬 Echo

A real-time chat application built with MERN stack + Socket.io.

## 🛠️ Tech Stack

**Frontend:**

- React + Vite
- TailwindCSS
- React Router DOM
- Axios
- Socket.io-client
- React Hot Toast

**Backend:**

- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- Socket.io
- Cloudinary

## ✨ Features

- 🔐 User authentication (Signup / Login)
- 💬 Real-time messaging
- 🟢 Online/Offline status
- 🔔 Unread message count
- 🖼️ Image sharing
- 👤 Profile management
